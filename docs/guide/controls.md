# Keyboard and mouse

The keys work anywhere outside a text box, so typing a tone's name can't remove a
pedal.

## Knobs

| Action | How |
| --- | --- |
| Turn a knob | Drag up or down, or scroll |
| Fine adjustment | Hold ++shift++ while dragging or scrolling |
| Reset to default | Double-click it |

## Chain

| Action | How |
| --- | --- |
| Select a block | ++left++ and ++right++, or click its card |
| Put the first block on the stage | ++enter++ |
| Add a block | **+** between two blocks, **+ Add block**, or ++g++ |
| Replace it | **Replace** on its card |
| Switch it on or off | **On** or **Off** on its card, its footswitch on the stage, or ++b++ |
| Move it | Drag its card, or press ++alt+left++ and ++alt+right++ |
| Remove it | **Remove** on its card, or ++delete++ |
| Close the gear picker, an open panel, or the stage | ++esc++ |
| Undo | ++ctrl+z++ |
| Redo | ++ctrl+y++ or ++ctrl+shift+z++ |

Undo steps back through your last 64 edits, including moves to another tone, so
unsaved work is never lost. One long turn of a knob counts as one edit.

## Tone Explorer

| Action | How |
| --- | --- |
| Open or close | ++ctrl+o++ |
| Load the next or previous tone | ++up++ and ++down++ |
| Close | ++esc++ |

## Everywhere

| Action | How |
| --- | --- |
| Previous or next tone | ++page-up++ and ++page-down++ |
| Start or stop monitoring | ++m++ |
| Practice tools | ++t++ |
| Metronome on or off | ++k++ |
| Tone Explorer | ++ctrl+o++ |
| Gear picker | ++g++ |
| Tone assistant | ++ctrl+j++ |
| Flip between old and new while trying a suggestion | ++ctrl+b++ |
| Save the tone | ++ctrl+s++ |
| Switch to scene 1, 2, 3, or 4 | ++1++, ++2++, ++3++, ++4++ |
