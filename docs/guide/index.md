# User guide

This guide takes you from a fresh checkout to playing through your speakers.
If you're new, read the first three pages in order. The rest are there when you
want them.

1. [Install](install.md) the tools and build the app.
2. [Connect your interface](setup.md) and hear your first tone.
3. [Get your latency down](monitoring.md) until it feels like an amp.

After that:

- [Load and save tones](tones.md)
- [Build a rig](board.md) from pedals, amps, and cabinets
- [Share tones](sharing.md) with other people
- [Tune and practice](tools.md) with the tuner, metronome, and fretboard
- [Keyboard and mouse](controls.md) controls
- [Troubleshooting](troubleshooting.md)

## What you need

| | |
| --- | --- |
| Computer | A Windows PC |
| Guitar connection | An audio interface with an instrument input |
| Speakers or headphones | Plugged into the interface for the lowest latency, or anywhere else if you can live with a little more |

A laptop's microphone jack or a webcam won't do. A guitar needs a proper
instrument input, and the app warns you if **Guitar in** is set to a microphone.
